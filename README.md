# Plaques moteurs

Application iPhone (PWA) pour relever sur le terrain les plaques signalétiques de moteurs électriques.

## Installer sur l'iPhone

1. Ouvrir l'adresse de l'app dans **Safari**.
2. Toucher **Partager** → **Sur l'écran d'accueil**.
3. Ouvrir l'app **depuis l'écran d'accueil**, puis remplir **Réglages** (nom, initiales, clé API).

> Les données de l'app installée sont séparées de celles de Safari : saisis la clé dans l'app installée.

## Données

Chaque iPhone garde ses propres relevés (photos comprises). Exporte régulièrement : iOS peut effacer les données d'une web app peu utilisée.

La clé API n'est jamais dans ce dépôt.
